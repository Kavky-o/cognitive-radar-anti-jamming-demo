# Cognitive Radar Anti-Jamming Demonstration

This repository hosts a video demonstration of a laboratory-based semi-physical radar–jammer experiment for cognitive radar anti-jamming.

## Demonstration

The video illustrates a feedback-driven anti-jamming process under changing jamming conditions:

1. Target detection performance initially degrades following a change in the jamming environment.
2. Using pulse-to-pulse feedback, the radar adapts the probing subpulse timing and duration through an online greedy-search method.
3. Target detection performance subsequently recovers after the waveform update.
